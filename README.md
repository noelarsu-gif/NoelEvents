# NoelEvents Control

Centro de control de bodas y eventos de Noel DJ · Music & Events.

- App web instalable (PWA) alojada en GitHub Pages: https://noelarsu-gif.github.io/noelevents/
- Datos en Firebase (Firestore + Authentication). Solo pueden entrar los correos autorizados en las reglas de Firestore.
- El código no contiene datos de clientes.
